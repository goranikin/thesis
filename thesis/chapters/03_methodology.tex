\chapter{Methodology}
\label{ch:methodology}

\section{Overview}
\label{sec:method-overview}

This thesis presents a methodology for training and evaluating diffusion-based neural solvers for routing problems.
First, a DIFUSCO-style model is trained with supervised denoising on solver-generated labels.
Second, the supervised checkpoint is optionally fine-tuned with a CADO-style reinforcement learning
objective that directly rewards the decoded solution quality.

    \centering
    \includegraphics[width=0.85\textwidth]{./figures/pipeline.png}
    \caption{
        Overview of the proposed training and evaluation pipeline for diffusion-based neural solvers.
        The pipeline consists of supervised denoising training followed by optional reinforcement learning (CADO-style) fine-tuning.
    }
    \label{fig:pipeline}
\end{figure}

The implementation covers three problem settings. For TSP, the model predicts a heatmap over
tour edges. For CVRP, the same edge-heatmap paradigm is extended to capacitated multi-route
solutions. For MDVRP, the implementation focuses on depot-assignment heatmaps as a first step
toward full multi-depot routing. This distinction is important: the TSP and CVRP experiments
report decoded route length and optimality gap, whereas the MDVRP experiment reports depot
assignment accuracy and capacity-violation rate.

\section{Model Architecture}
\label{sec:architecture}

The core model follows the DIFUSCO design described in \cref{subsec:difusco}: a categorical
diffusion process corrupts binary solution variables, and an edge-aware graph neural network
predicts the clean binary structure from a noisy intermediate state. The implementation uses
two model sizes. The small model has hidden dimension 128 and 6 AGNN layers, while the paper
model has hidden dimension 256 and 12 AGNN layers.

For TSP and CVRP, the binary variable represents edge membership. The graph input contains
node coordinates, edge indices, edge distances, and the current noisy edge state $x_t$. The
network returns logits for each edge, and the probability of class 1 is interpreted as the
heatmap value indicating that the edge should be selected. CVRP additionally includes customer
demands and vehicle capacity during decoding, although capacity is not used directly in the
supervised denoising loss.

For MDVRP, the model predicts customer--depot assignment edges rather than full routes. The
decoder converts the assignment heatmap into a depot choice for each customer while respecting
aggregate depot capacity where possible. This simplified output space makes MDVRP feasible as
an initial extension, but it does not yet solve the complete route construction problem inside
each depot.

\section{Supervised Training}
\label{sec:supervised}

Supervised training uses the ground-truth binary edge labels generated by classical solvers.
At each training step, a timestep $t$ is sampled uniformly, the ground-truth label $x_0$ is
corrupted by the categorical diffusion process to obtain $x_t$, and the model predicts
$x_0$ from $(g,x_t,t)$. The loss is the cross-entropy between the predicted logits and the
ground-truth binary labels:
\[
\mathcal{L}_{\mathrm{SL}}
= \operatorname{CE}\big(f_\theta(g,x_t,t), x_0\big).
\]

All supervised runs use $T=1000$ diffusion steps with a linear beta schedule from $10^{-4}$ to
$0.02$. Optimization uses AdamW with learning rate $2\times10^{-4}$, weight decay $10^{-4}$,
cosine learning-rate decay, and gradient clipping at norm 1.0. The local configuration uses
batch size 16, while remote A100 runs use batch size 64. Validation uses 50 denoising steps
subsampled from the training diffusion chain with a cosine schedule.

\section{CADO Fine-Tuning}
\label{sec:cado}

CADO fine-tuning starts from a supervised DIFUSCO checkpoint and optimizes the decoded
solution cost using REINFORCE. During a rollout, the model samples a denoising trajectory with
$M_{\mathrm{train}}=5$ inference steps and accumulates the log-probabilities of the sampled
reverse transitions. After the final heatmap is thresholded or decoded, the reward is computed
from the resulting hard solution.

For TSP and CVRP, the standard reward (SR) is the negative decoded solution length. The
label-centered reward (LCR) subtracts the ground-truth length and therefore rewards the
negative optimality gap. In the implementation, SR uses batch-normalized advantages:
\[
A_i = \frac{R_i - \bar{R}}{\operatorname{std}(R)+10^{-6}},
\qquad
\mathcal{L}_{\mathrm{RF}}
= -\frac{1}{B}\sum_{i=1}^{B} A_i \log p_\theta(\tau_i).
\]
The CADO training code also includes a small entropy term based on the sampled log
probabilities to encourage exploration.

To reduce memory cost and preserve the supervised representation, CADO uses Hybrid-FT. LoRA
with rank 2 is applied to most of the backbone, while the final GNN layer and output head are
fully trainable. In the TSP small-model run, this reduced the trainable parameter count from
approximately 953K parameters to 178K parameters, or 18.7\% of the model.

\section{Decoding and Evaluation}
\label{sec:decoding}

At evaluation time, the model generates a probabilistic heatmap with a reduced number of
denoising steps rather than all $T=1000$ diffusion steps. The supervised runs use
$M_{\mathrm{eval}}=50$; CADO runs use the value specified by the corresponding configuration
or experiment log. TSP decoding selects high-probability edges and applies 2-opt local search.
CVRP decoding ranks undirected edge scores by heatmap probability divided by Euclidean
distance, greedily adds edges subject to degree, subtour, and capacity checks, extracts
depot-rooted routes, and optionally applies per-route 2-opt. The CVRP validation metric is the
percentage optimality gap
\[
\mathrm{Gap}(\%) =
\frac{L_{\mathrm{pred}} - L_{\mathrm{gt}}}{L_{\mathrm{gt}}}\times 100,
\]
where $L_{\mathrm{pred}}$ is the decoded route length and $L_{\mathrm{gt}}$ is the
solver-generated reference length.

MDVRP decoding operates at the assignment level. It averages directed customer--depot edge
probabilities, processes customers in descending order of confidence margin, and assigns each
customer to the highest-scoring depot with remaining capacity. The reported MDVRP metrics are
assignment accuracy and capacity-violation rate.

\section{Implementation}
\label{sec:implementation}

The codebase separates supervised diffusion solvers and CADO fine-tuning. The
\texttt{difusco/} package contains supervised TSP, CVRP, and MDVRP implementations, including
datasets, model definitions, trainers, decoders, and evaluation entry points. The
\texttt{cado/} package wraps the corresponding supervised models with rollout and reward
functions for REINFORCE fine-tuning. Experiment settings are managed with Hydra under
\texttt{configs/}, including problem data, model size, diffusion schedule, training settings,
and inference settings.

Datasets are generated under \texttt{data\_generation/}. TSP labels are generated with
Concorde, while CVRP and MDVRP labels are generated with PyVRP. Runs are logged to Weights
\& Biases, and checkpoints are saved under \texttt{checkpoints/}. The main experiments use
seed 42 for training splits and model initialization, with local runs on Apple MPS and larger
CVRP/MDVRP runs on a VESSL A100 instance.
